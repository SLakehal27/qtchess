# Qtchess

Qtchess is a complete and simplified rewrite of an old C++ chess assignment made during INF1015.

## Dependencies

- C++
- cmake (<3.7.0)
- QT5

## Installation

```bash
git clone https://github.com/SLakehal27/qtchess
cd ./qtchess
```

## Usage

A `build.sh` script is included in the project and handles building the project with cmake and executing the binary file.

```bash
./build.sh
```
